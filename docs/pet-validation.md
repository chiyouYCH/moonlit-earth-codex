# 望归 · Lunar 验证说明

本页汇总原制作记录中的图集校验、逐帧复核和预览检查，不包含个人机器路径，也不把离线检查表述为 Codex 实机播放验证。

## 图集严格校验

原 `validation.json` 记录如下：

| 项目 | 结果 |
| --- | --- |
| 校验结果 | 通过；错误 0，警告 0 |
| 格式 / 色彩模式 | WebP / RGBA |
| 图集尺寸 | 1536 × 1872 |
| 网格 / 单格尺寸 | 8 列 × 9 行 / 192 × 208 |
| 有效帧 | 57 |
| 未使用格 | 15，均完全透明 |
| 透明像素隐藏 RGB 残留 | 0 像素 |

校验对象为发布包中的 [spritesheet.webp](../pet/package/wanggui-lunar/spritesheet.webp)。仓库保留了 [上游校验脚本](../vendor/hatch-pet/scripts/validate_atlas.py)，便于重新检查文件。

## 逐帧与视觉检查

原 `visual-qa.json` 对九个状态均记录为通过，检查依据是完整帧序列总览，以及 GIF 帧数、时长和循环元数据。复核包括角色与配色一致性、裁切、游离杂点、待机的轻微非静态变化、方向步伐交替、等待动作的同侧伸手，以及跳跃位移和站立比例。

原逐帧报告的 `stable-slots` 提醒已在视觉复核中审阅；这类提醒要求注意运动稳定性与裁切，不能用来推导已经验证实时播放。静态参考可查看 [完整帧总览](../pet/contact-sheet.png)，动画资源见 [GIF 预览](../pet/previews/)。

## 离线预览与兼容性依据

原制作说明记录了离线预览页自动化冒烟测试通过，覆盖九状态切换、帧坐标、缩放、定时、暂停和减少动态效果逻辑。本仓库提供 [预览页](../pet/preview.html) 和 [测试脚本](../scripts/test_preview.cjs)。

制作时只读核对过 Codex 26.915.31945 的宠物加载格式。该记录不是对其他版本的兼容性保证。

## 尚未验证

图片查看器未直接验证实时动画播放；尚未观察 Codex 应用内的实际播放效果。因此，本项目不宣称完成 Codex 实机动画验收。使用者仍需安装、手动选择宠物，并在自己的 Codex 版本中检查动画、缩放与状态切换。
